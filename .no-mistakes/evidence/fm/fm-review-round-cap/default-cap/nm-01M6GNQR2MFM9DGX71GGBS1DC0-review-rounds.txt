    The captain's decision says what to do with the spare seconds of a stretched strength set: "D. Rest. The one-time explainer still says the opposite: "Done jumps you ahead - Finished early? Tap **Done** to move straight to what's next. You set the pace." ADR-0010 admits the work window has no on-screen cue for the spare seconds, so this card is the only guidance a user gets. README.md:69 says the same thing: "A prominent 'Done' ends the window the moment you finish your reps". Concrete case: a user with a lower-back flag picks 60 minutes. The fit stretches each rep set by about a minute (ADR-0010 consequence). Fixing this means changing user-facing copy, which is a product call. Option 1: reword the explainer point and the README line to say the countdown includes rest after the reps and Done is for moving on early. Option 2: accept the current wording.
