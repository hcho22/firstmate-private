  description: |
    The case 'default resumed identity refuses session lock contention' held the lock for a fixed 15s. fm-spawn.sh's bounded acquire counts 50 attempts, not time, and each contended attempt forks sh and `ps -o lstart`, so on this macOS host the window is about 14s. - id: herdr-bounded-lock-attempt-counted
  severity: info
  file: bin/fm-spawn.sh:2111
  action: no-op
  description: |
    Product note, not changed in this test phase. spawn_herdr_presentation_order_lock_acquire and fm_backend_herdr_kill bound their non-waiting lock acquire by 50 attempts with a 0.1s sleep, which reads like about 5s. Each failed fm_lock_try_acquire also forks liveness probes (sh for the pid, ps -o lstart), so the real window is about 14s on this macOS host and varies with load.
